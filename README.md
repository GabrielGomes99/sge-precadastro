# SGE Pré-cadastro

Este repositório é um espelho local do portal público `sge-precadastro`. Os arquivos do portal foram copiados de `C:/sge-system/web/precadastro/`; mudanças de backend e administração permanecem no repositório SGE, cuja branch `feature/validacao` é a fonte de verdade para alterações que não pertencem ao portal.

Quando houver acesso à rede, publique esta branch com:

```bash
git remote add origin https://github.com/GabrielGomes99/sge-precadastro.git
git push -u origin feature/validacao
```
